# Dashboard FLOTA | Alucinando Agency

Dashboard de resultados en tiempo real para **FLOTA**, desarrollado por **Alucinando Marketing**.

## Características
- Integración directa con Meta Ads Graph API v19.0.
- Visualización de métricas de Mensajes, Leads y Posicionamiento.
- Seguimiento de presupuesto mensual (S/ 2,000.00).
- Gráficos interactivos de crecimiento y rendimiento diario.
- Optimizado para visualización móvil y escritorio.

## Requisitos
- Python 3.8+
- Token de acceso a la API de Meta Ads.

## Instalación
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Wolf-Negro/dashboard-flota.git
   ```
2. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Configurar variables de entorno:
   Crear un archivo `.env` con las credenciales de Meta y el ID de la cuenta publicitaria de FLOTA.

## Ejecución
```bash
python app.py
```
